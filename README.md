# PsychoPy Builder: five experiments

After the Stroop demonstration, you have 90 minutes to work through five
short Builder tasks. Each folder has a partly built experiment and a guide.
Open the `.psyexp` file in `exp code/` and follow its guide.

1. [01 Simon Guidance](01_simon/01%20Simon%20Guidance.md)
2. [02 Size Bisection Guidance](02_size_bisection/02%20Size%20Bisection%20Guidance.md)
3. [03 Duration Reproduction Guidance](03_duration_reproduction/03%20Duration%20Reproduction%20Guidance.md)
4. [04 Orientation Reproduction Guidance](04_orientation_reproduction/04%20Orientation%20Reproduction%20Guidance.md)
5. [05 Visual Search Guidance](05_visual_search/05%20Visual%20Search%20Guidance.md)

The Flow, instruction screens and feedback are already in place. Each
conditions CSV has a few `____` cells for you to fill from the experiment
design. You will add components in the earlier tasks and complete the key
Code tabs in the later ones. Follow the TODO steps in each guide.

The Builder files are configured for the trial counts shown in each guide.
In class, run only enough trials to check that your changes work; press
Escape when you need to move to the next task. You do not need to finish
all configured trials during the 90-minute session.

Each guide explains the design, shows exactly what to build or change, and
ends with short questions. The five tasks are budgeted for **82 minutes**,
leaving **8 minutes** to switch files and discuss your results.
